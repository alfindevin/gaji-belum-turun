# Gaji Belum Turun 💸

Game browser absurd tentang bertahan hidup dari tanggal 25 sampai tanggal 1 dengan saldo terbatas.

## Fitur MVP

- Gameplay 6 hari: tanggal 25–30
- Random event setiap permainan
- Statistik saldo, mental, kenyang, sosial, dan utang
- Pilihan dengan konsekuensi berbeda
- Beberapa ending lucu
- Survival score
- Web Share API + fallback copy
- Responsive untuk HP dan desktop
- Siap deploy ke Vercel

## Jalankan lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000

## Deploy

Import repository ini ke Vercel. Framework akan terdeteksi otomatis sebagai Next.js.

## Ide fase berikutnya

Leaderboard, daily challenge, share-card berbentuk gambar, lebih banyak random event, achievements, sound effects, dan analytics.
